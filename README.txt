UPLOAD TO GITHUB:
1. Download and extract this ZIP.
2. Open your GitHub repository for expertchimneyrepairservice.shop.
3. Add file → Upload files.
4. Upload index.html and the entire assets folder (including all images).
5. Commit changes.
6. Open Settings → Pages, select branch main and folder /(root), then Save.
7. In Settings → Pages, set custom domain: expertchimneyrepairservice.shop.
8. In your domain provider's DNS, set A records for @:
   185.199.108.153
   185.199.109.153
   185.199.110.153
   185.199.111.153
   Add CNAME for www to YOUR-GITHUB-USERNAME.github.io (replace with your actual GitHub Pages host).
9. After DNS has updated, enable Enforce HTTPS in GitHub Pages.
