UPLOAD TO GITHUB:
1. Download this ZIP and extract it.
2. Open your GitHub repository for expertchimneyrepairservice.shop.
3. Tap Add file → Upload files.
4. Upload index.html, favicon.svg, and the entire assets folder with all image files.
5. Tap Commit changes.
6. Open Settings → Pages. Choose Deploy from a branch, branch main, folder /(root), then Save.
7. In Settings → Pages, enter custom domain expertchimneyrepairservice.shop and save.
8. In the domain provider DNS panel, add A records for host @:
